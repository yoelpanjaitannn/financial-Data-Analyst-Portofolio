\# Financial Data Analyst Portfolio



\## Project 1: MTDL Financial Statement Analysis 2022-2023



\### Overview

Analisis laporan keuangan PT Metrodata Electronics Tbk (MTDL), perusahaan distribusi IT terbesar di Indonesia, menggunakan Python dan AI.



\### Tools Used

\- Python 3.11, Pandas, Matplotlib

\- pdfplumber (ekstrak data dari Annual Report PDF)

\- Qwen2.5-Coder 32B (AI analysis)

\- JupyterLab



\### Key Findings

\- Revenue tumbuh 5.23% dari Rp 20.9T ke Rp 22.1T

\- Net Profit Margin membaik dari 4.13% ke 4.26%

\- ROE masih kuat di 18.66% meski turun tipis

\- DER melewati 1x — perlu dipantau
